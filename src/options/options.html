Jira Unsuckify

Behaviour

Unscroll boards
The main switch.
Sticky column headers
Headers stay on screen while you scroll.
Skip drawing off-screen cards
Helps on very large boards. Costs an accurate scrollbar size, and the browser's find-on-page can miss cards.
Debug mode
Outlines every matched element and logs to the console.

Custom Jira domains

Only needed if your Jira is not on atlassian.net. Chrome will ask you to approve each one.

    Selector overrides

    For when Jira changes its DOM and the extension stops working. Paste JSON that maps a selector name to a new CSS selector. Anything you leave out keeps its shipped value. An empty box means "use the defaults".
